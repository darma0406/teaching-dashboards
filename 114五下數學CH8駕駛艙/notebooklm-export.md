## 焦點一：認識比率

# 教學主題
認識比率

# 教學目標
學生能用部分量與全體量說明比率。

# 核心概念
比率 = 部分量 ÷ 全體量。比率可用直式分數表示，例如：

  20
 ----
  25

# 教學流程
生活情境導入，找部分量和全體量，用直式分數表示，再比較不同總量。

# 範例題
25人中20人到校，出席率是多少？

# 課堂互動
請學生拖曳「部分量」與「全體量」配對。

# 總結
比率是公平比較的工具。

## 焦點二：認識百分率

# 教學主題
認識百分率

# 教學目標
學生能說明百分率是分母100的比率。

# 核心概念
20% = 20/100，100%代表全部。

# 教學流程
手機電量導入，使用100格圖，連結分數與百分率。

# 範例題
18/100用百分率表示是多少？

# 課堂互動
拖動百分率滑桿並說明亮起幾格。

# 總結
百分率是生活中常用的比率語言。

## 焦點三：分數小數百分率互換

# 教學主題
分數小數百分率互換

# 教學目標
學生能在三種表示法間轉換。

# 核心概念
同一個比率可以寫成分數、小數、百分率。

# 教學流程
三欄對照，操作分子分母，練習百分率與小數互換。

# 範例題
3/8 = 0.375 = 37.5%。

# 課堂互動
拖曳百分率到相等的小數。

# 總結
先理解比率，再使用轉換技巧。

## 焦點四：百分率應用

# 教學主題
百分率應用

# 教學目標
學生能解決整體量、部分量、百分率問題。

# 核心概念
整體量×百分率=部分量；部分量÷整體量=百分率。

# 教學流程
判斷已知量，選擇乘或除，檢查答案是否合理。

# 範例題
25題的96%是24題。

# 課堂互動
切換模式並說明為什麼用乘法或除法。

# 總結
先找整體量，再決定運算。

## 焦點五：折扣與加成

# 教學主題
折扣與加成

# 教學目標
學生能把生活促銷語言轉成百分率並計算。

# 核心概念
打折是付多少，off是減多少，加成是加多少。

# 教學流程
翻譯語意，找實付比例，計算現價或定價。

# 範例題
30% off 等於付70%。

# 課堂互動
拖曳生活用語到實付比例。

# 總結
先判斷付、減、加，再計算。

標題：折扣語言
重點：打折是付原價的百分率。
圖片建議：價格標籤。

# Slide 2

重點：off是減少的百分率。
圖片建議：促銷海報。

# Slide 3
標題：加成語言
